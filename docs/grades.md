# 等級（アルファベット評価）の定義

このゲームの能力表現の中核。データを書き起こす前に必ずここを読むこと。

## 段階と能力値の対応

能力は S および A〜G の8段階。多くの能力には裏側に数値（能力値）があり、
等級は数値から一意に決まる。

| 等級 | 能力値 |
|---|---|
| S | 90 以上 |
| A | 80〜89 |
| B | 70〜79 |
| C | 60〜69 |
| D | 50〜59 |
| E | 40〜49 |
| F | 20〜39 |
| G | 19 以下 |

**書き起こしの検算に使うこと。** 数値と等級が矛盾していたら、どちらかの
読み取りを誤っている。`src/generate.py` が生成時に不一致を警告する。

## 等級の色

| 等級 | 色 | 近似値 |
|---|---|---|
| S | 白に近い薄ピンク | `#f7dbe6` |
| A | S より濃い薄ピンク | `#f0a0c0` |
| B | 赤 | `#e03c3c` |
| C | 濃いオレンジ | `#e07b1e` |
| D | 薄いオレンジ | `#f2ac52` |
| E | 緑 | `#4cb050` |
| F | 青（少し薄め） | `#5b8fd6` |
| G | 灰 | `#9aa0aa` |

S から G へ向かって「薄ピンク → 赤 → 橙 → 緑 → 青 → 灰」と推移する。
赤系が良い、寒色系が悪い、という並びであることに注意（一般的な信号色の
感覚とは逆になる区間がある）。

## 等級を使わない能力

- **先発適性 / 中継適性 / 抑え適性** … `◎` `○` `△` `－` の4段階。等級ではない。
- **変化球の変化量** … 1〜7段階の数値。ただしストレート系のみ変化量の概念が
  なく常に1段階。
- **特殊能力に付くアルファベット** … A〜G の段階だが、上記の等級とは
  少し異なる考え方。**C 以下（C〜G）は能力名とアルファベットの色を薄くして
  表示する**（マイナス寄りの評価であることを示すため）。

## 変化球の等級表示

変化球は「球威」「制球」「変化量」の3つで構成され、球威と制球には数値の
概念がなく等級のみ。表示は**1つの四角オブジェクト**で行う。

- 四角の**塗りつぶし色** = 球威の等級色
- 四角の中の**左の黒文字** = 球威の等級
- 四角の中の**右のカラー文字** = 制球の等級（文字色は制球の等級色）

ステータス欄の等級が「背景なしの色付き文字」なのに対し、変化球は
「等級色で塗った四角＋黒文字＋カラー文字」。同じ等級でも表現が違う。
